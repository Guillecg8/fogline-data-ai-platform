# Fogline Data & AI Platform

End-to-end data and AI platform for Fogline Hospitality Group, a fictional
hospitality and retail operator in San Francisco. Three projects, one platform.

| # | Project | What it proves | Status |
|---|---------|----------------|--------|
| 01 | Revenue Lakehouse | Medallion pipelines, data contracts, forecasting | Planned |
| 02 | [Ops Knowledge Copilot](projects/02-ops-knowledge-copilot) | RAG + MCP with evals in CI | In progress |
| 03 | Agentic Commerce Gateway | Agent-ready catalog with spend policies | Planned |

## Quickstart

    uv sync --all-packages
    uv run poe check

Fogline is fictional. Synthetic data is always labeled as synthetic.
